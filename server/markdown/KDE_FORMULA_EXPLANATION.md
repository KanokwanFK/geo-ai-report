# 📊 คำอธิบายสูตร Kernel Density Estimation สำหรับ Heat Map

## 🎯 ภาพรวม

Heat Map ในระบบรายงานปัญหาใช้เทคนิค **Kernel Density Estimation (KDE)** เพื่อแสดงความหนาแน่นของรายงานในแต่ละพื้นที่ โดยปรับปรุงสูตรดั้งเดิมให้เหมาะสมกับลักษณะของข้อมูลรายงาน

## 📐 สูตรพื้นฐาน Kernel Density Estimation

### สูตรหลัก:
```
f(x) = (1/nh) * Σ K((x-xi)/h)
       i=1 to n
```

### คำอธิบายตัวแปร:

| ตัวแปร | ชื่อ | คำอธิบาย | ตัวอย่างค่า |
|--------|------|----------|------------|
| **f(x)** | Density Value | ค่าความหนาแน่นที่ตำแหน่ง x | 0.001 - 10.0 |
| **n** | Sample Size | จำนวนข้อมูลจุดทั้งหมด | 50, 100, 500 |
| **h** | Bandwidth | รัศมีการกระจาย/ความนุ่มนวล | 0.01 (เฉียบคม) - 0.1 (เบลอ) |
| **K** | Kernel Function | ฟังก์ชันเคอร์เนล (Gaussian) | 0 - 0.399 |
| **xi** | Data Point | ตำแหน่งของจุดข้อมูลที่ i | [13.7563, 100.5018] |
| **x** | Target Point | ตำแหน่งที่ต้องการคำนวณ | [13.7500, 100.5000] |

## 🧮 Gaussian Kernel Function

### สูตร:
```
K(u) = (1/√(2π)) * e^(-u²/2)
```

### โดยที่:
```
u = (x - xi) / h
```

### คำอธิบายการทำงาน:

1. **คำนวณระยะห่างมาตรฐาน**: 
   ```
   u = (target_position - data_point_position) / bandwidth
   ```

2. **ใช้ฟังก์ชันเกาส์เซียน**:
   - ค่าคงที่: `1/√(2π) ≈ 0.399`
   - ส่วน Exponential: `e^(-u²/2)`

3. **ผลลัพธ์**:
   - ระยะห่าง = 0 → ค่าสูงสุด (≈ 0.399)
   - ระยะห่างเพิ่ม → ค่าลดลงแบบโค้งระฆัง
   - ระยะห่างมาก → ค่าเข้าใกล้ 0

## 🎨 การปรับปรุงสำหรับระบบรายงาน

### สูตรที่ปรับปรุงแล้ว:
```
Weight = [(1/nh) * K(0,h)] * [StatusWeight * UrgencyMultiplier / √ReportAge]
```

### ปัจจัยเพิ่มเติม:

#### 1. **Status Weight** (น้ำหนักตามสถานะ)

| สถานะ | ค่าน้ำหนัก | เหตุผล |
|-------|-----------|--------|
| **step1** (เริ่มยื่น) | 4.0 | ต้องการความสนใจมากที่สุด |
| **step2** (ตรวจสอบ) | 3.5 | กำลังดำเนินการ |
| **step3** (รอดำเนินการ) | 3.0 | รอคิว |
| **step4** (กำลังแก้ไข) | 2.5 | กำลังดำเนินการ |
| **step5** (เสร็จสิ้น) | 1.0 | ความสำคัญต่ำ |
| **rejected** (ปฏิเสธ) | 0.5 | ความสำคัญต่ำสุด |

#### 2. **Urgency Multiplier** (ตัวคูณความเร่งด่วน)

```
UrgencyMultiplier = รายงานค้างนาน ? 1.5 : 1.0
```

#### 3. **Report Age Factor** (ปัจจัยอายุรายงาน)

```
AgeFactor = 1 / √(อายุรายงานเป็นวัน)
```

- รายงานใหม่ (1 วัน): `1/√1 = 1.0`
- รายงาน 4 วัน: `1/√4 = 0.5`
- รายงาน 9 วัน: `1/√9 = 0.33`

## 📊 ตัวอย่างการคำนวณ

### ข้อมูลตัวอย่าง:
- **จำนวนรายงาน (n)**: 100
- **Bandwidth (h)**: 0.01
- **รายงานสถานะ step1**: อายุ 2 วัน, ไม่ค้างนาน

### ขั้นตอนการคำนวณ:

#### 1. คำนวณ Density Value:
```
densityValue = (1 / (100 * 0.01)) * gaussianKernel(0, 0.01)
             = (1 / 1) * 0.399
             = 0.399
```

#### 2. คำนวณปัจจัยเพิ่มเติม:
```
statusWeight = 4.0        (step1)
urgencyMultiplier = 1.0   (ไม่ค้างนาน)
reportAge = 2             (วัน)
ageFactor = 1/√2 = 0.707
```

#### 3. คำนวณน้ำหนักรวม:
```
adjustedWeight = (4.0 * 1.0 * 0.707) * 0.399
               = 2.828 * 0.399
               = 1.128
```

#### 4. ปรับค่าขั้นสุดท้าย:
```
finalWeight = 1.128 * 100 = 112.8
clampedWeight = min(10, max(1, 112.8)) = 10
```

## 🎯 ผลลัพธ์ในการแสดงผล

### Heat Map Colors:
- **น้ำหนัก 1-2**: สีน้ำเงินเข้ม (ความหนาแน่นต่ำ)
- **น้ำหนัก 3-4**: สีเขียว (ความหนาแน่นปานกลาง)
- **น้ำหนัก 5-6**: สีเหลือง (ความหนาแน่นสูง)
- **น้ำหนัก 7-8**: สีส้ม (ความหนาแน่นสูงมาก)
- **น้ำหนัก 9-10**: สีแดง (ความหนาแน่นสูงสุด)

### ความหมายของสี:
- **สีแดง**: พื้นที่ที่มีรายงานใหม่/เร่งด่วนมาก
- **สีส้ม-เหลือง**: พื้นที่ที่ต้องให้ความสนใจ
- **สีเขียว-น้ำเงิน**: พื้นที่ปกติหรือรายงานเก่า

## 🔧 การปรับแต่งพารามิเตอร์

### Bandwidth (h):
- **h = 0.005**: Heat map เฉียบคม (จุดแยกชัด)
- **h = 0.01**: สมดุล (ค่าเริ่มต้น)
- **h = 0.05**: Heat map เบลอ (พื้นที่กว้าง)

### Status Weights:
- เพิ่มค่าสำหรับสถานะที่ต้องการความสนใจมากขึ้น
- ลดค่าสำหรับสถานะที่สำคัญน้อยลง

### Urgency Multiplier:
- เพิ่มค่าสำหรับรายงานที่ค้างนานมาก
- ปรับเกณฑ์การตัดสินใจว่า "ค้างนาน"

## 📈 ข้อดีของวิธีนี้

1. **สะท้อนความเป็นจริง**: รายงานใหม่และเร่งด่วนได้รับความสนใจมากกว่า
2. **ปรับแต่งได้**: สามารถปรับพารามิเตอร์ตามนpolicy องค์กร
3. **เข้าใจง่าย**: สีแสดงความเร่งด่วนชัดเจน
4. **ประสิทธิภาพดี**: คำนวณเร็วและแสดงผลได้เรียลไทม์

## 🎨 การใช้งานใน Code

```typescript
// ตัวอย่างการใช้งานใน React Component
const calculateWeight = (report: Report) => {
    const n = reports.length;
    const h = 0.01;
    
    // คำนวณตามสูตร KDE ที่ปรับปรุงแล้ว
    const densityValue = (1 / (n * h)) * gaussianKernel(0, h);
    const statusWeight = getStatusWeight(report.status);
    const urgencyMultiplier = report.is_overdue ? 1.5 : 1.0;
    const ageFactor = 1 / Math.sqrt(reportAge);
    
    const adjustedWeight = statusWeight * urgencyMultiplier * ageFactor * densityValue;
    
    return Math.max(1, Math.min(10, adjustedWeight * 100));
};
```
