# ระบบ API สำหรับรายงานปัญหาเชิงพื้นที่

## คำอธิบายทั่วไป
ระบบ API นี้พัฒนาด้วย Node.js และ PostgreSQL สำหรับการจัดการรายงานปัญหาต่าง ๆ ในพื้นที่ พร้อมระบบการจัดการผู้ใช้ การอัปโหลดรูปภาพ และระบบแจ้งเตือน

## ฟีเจอร์หลัก

### 1. ระบบการจัดการผู้ใช้และการเข้าสู่ระบบ
- สมัครสมาชิกใหม่
- เข้าสู่ระบบ
- ดูข้อมูลโปรไฟล์ผู้ใช้
- แก้ไขข้อมูลโปรไฟล์ผู้ใช้
- เปลี่ยนรหัสผ่าน

### 2. ระบบการจัดการผู้ดูแลระบบ (Admin)
- ดูข้อมูลผู้ใช้ทั้งหมด (สำหรับ Admin)
- สร้างผู้ดูแลระบบ
- ลบผู้ใช้งาน (สำหรับ Admin)
- อัพเดทสถานะ Admin

### 3. ระบบการจัดการประเภทปัญหา
- ดูประเภทปัญหาทั้งหมด
- ดูประเภทปัญหาตาม ID
- สร้างประเภทปัญหาใหม่ (สำหรับ Admin)
- แก้ไขประเภทปัญหา (สำหรับ Admin)
- ลบประเภทปัญหา (สำหรับ Admin)

### 4. ระบบการจัดการรายงาน
- สร้างรายงานใหม่
- ดูรายงานทั้งหมดพร้อมรายละเอียด (ใช้ view)
- ดูรายงานตาม ID
- อัพเดทสถานะรายงาน (สำหรับ Admin)
- แก้ไขรายละเอียดรายงาน
- ลบรายงาน
- ดูประวัติการเปลี่ยนแปลงสถานะรายงาน

### 5. ระบบการจัดการรูปภาพ
- อัปโหลดรูปภาพสำหรับรายงาน
- อัปโหลดรูปภาพหลายไฟล์สำหรับรายงาน
- ดูรูปภาพสำหรับรายงาน
- ลบรูปภาพ

### 6. ระบบการแจ้งเตือน
- ดูการแจ้งเตือนสำหรับผู้ใช้
- สร้างการแจ้งเตือน
- ทำเครื่องหมายว่าอ่านแล้ว
- ทำเครื่องหมายอ่านทั้งหมดสำหรับผู้ใช้
- นับจำนวนการแจ้งเตือนที่ยังไม่ได้อ่าน
- ลบการแจ้งเตือน

### 7. ระบบการตั้งค่าระบบ
- ดูการตั้งค่าทั้งหมด
- ดูการตั้งค่าตาม key
- สร้าง/อัพเดทการตั้งค่า
- แก้ไขการตั้งค่า
- ลบการตั้งค่า

### 8. ระบบแดชบอร์ดและสถิติ
- ดูสถิติแดชบอร์ด
- ดูรายงานจำแนกตามประเภทปัญหา
- ดูรายงานล่าสุด

## การติดตั้งและใช้งาน

### ข้อกำหนดระบบ
- Node.js (เวอร์ชัน 16 ขึ้นไป)
- PostgreSQL (เวอร์ชัน 12 ขึ้นไป)
- npm หรือ yarn

### การติดตั้ง
1. ติดตั้ง dependencies:
   ```bash
   npm install
   ```

2. ติดตั้งและตั้งค่าฐานข้อมูล PostgreSQL
3. สร้างฐานข้อมูลชื่อ `report_system`
4. รันคำสั่ง SQL เพื่อสร้างตารางและข้อมูลตัวอย่าง

### การเริ่มใช้งาน
```bash
node server.js
```

เซิร์ฟเวอร์จะทำงานที่ `http://localhost:3003`

## เส้นทาง API หลัก

### การจัดการผู้ใช้
- `POST /api/auth/register` - สมัครสมาชิก
- `POST /api/auth/login` - เข้าสู่ระบบ
- `GET /api/users/:id` - ดูข้อมูลผู้ใช้
- `PUT /api/users/:id` - แก้ไขข้อมูลผู้ใช้
- `PUT /api/users/:id/password` - เปลี่ยนรหัสผ่าน

### การจัดการ Admin
- `GET /api/admin/users` - ดูผู้ใช้ทั้งหมด
- `POST /api/admin/create` - สร้าง Admin
- `PUT /api/admin/:admin_id/status` - อัพเดทสถานะ Admin
- `DELETE /api/admin/users/:id` - ลบผู้ใช้

### การจัดการประเภทปัญหา
- `GET /api/problem-types` - ดูประเภทปัญหาทั้งหมด
- `GET /api/problem-types/:id` - ดูประเภทปัญหาตาม ID
- `POST /api/problem-types` - สร้างประเภทปัญหา
- `PUT /api/problem-types/:id` - แก้ไขประเภทปัญหา
- `DELETE /api/problem-types/:id` - ลบประเภทปัญหา

### การจัดการรายงาน
- `POST /api/reports` - สร้างรายงาน
- `GET /api/reports` - ดูรายงานทั้งหมด
- `GET /api/reports/:id` - ดูรายงานตาม ID
- `PUT /api/reports/:id/status` - อัพเดทสถานะรายงาน
- `PUT /api/reports/:id` - แก้ไขรายงาน
- `DELETE /api/reports/:id` - ลบรายงาน
- `GET /api/reports/:id/status-history` - ดูประวัติสถานะ

### การจัดการรูปภาพ
- `POST /api/reports/:id/images` - อัปโหลดรูปภาพเดี่ยว
- `POST /api/reports/:id/images/multiple` - อัปโหลดหลายรูปภาพ
- `GET /api/reports/:id/images` - ดูรูปภาพของรายงาน
- `DELETE /api/images/:id` - ลบรูปภาพ

### การจัดการการแจ้งเตือน
- `GET /api/users/:user_id/notifications` - ดูการแจ้งเตือน
- `POST /api/notifications` - สร้างการแจ้งเตือน
- `PUT /api/notifications/:id/read` - ทำเครื่องหมายอ่าน
- `PUT /api/users/:user_id/notifications/read-all` - อ่านทั้งหมด
- `GET /api/users/:user_id/notifications/unread-count` - นับที่ยังไม่อ่าน
- `DELETE /api/notifications/:id` - ลบการแจ้งเตือน

### การตั้งค่าระบบ
- `GET /api/settings` - ดูการตั้งค่าทั้งหมด
- `GET /api/settings/:key` - ดูการตั้งค่าตาม key
- `POST /api/settings` - สร้าง/อัพเดทการตั้งค่า
- `PUT /api/settings/:key` - แก้ไขการตั้งค่า
- `DELETE /api/settings/:key` - ลบการตั้งค่า

### แดชบอร์ดและสถิติ
- `GET /api/dashboard/stats` - ดูสถิติแดชบอร์ด
- `GET /api/dashboard/reports-by-type` - รายงานตามประเภท
- `GET /api/dashboard/recent-reports` - รายงานล่าสุด

## ข้อกำหนดการอัปโหลดรูปภาพ
- ขนาดไฟล์สูงสุด: 5MB
- ประเภทไฟล์ที่รองรับ: .jpg, .jpeg, .png, .gif
- รูปภาพจะถูกเก็บในโฟลเดอร์ `uploads/`
- สามารถเข้าถึงรูปภาพได้ที่ `http://localhost:3003/uploads/filename`

## การทดสอบ
ใช้ไฟล์ `Postman_Collection.json` เพื่อนำเข้า collection ใน Postman และทดสอบ API ทั้งหมด
ดูคู่มือการทดสอบแบบละเอียดใน `API_Testing_Guide.md`

## หมายเหตุ
- ระบบใช้ PostgreSQL พร้อม PostGIS extension สำหรับข้อมูลเชิงพื้นที่
- มี triggers สำหรับอัพเดท updated_at อัตโนมัติ
- มี views สำหรับ query ที่ซับซ้อน
- มี indexes สำหรับประสิทธิภาพ
- รองรับ pagination และ filtering
